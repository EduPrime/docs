# Importador Censo

O **Importador Censo** no EduPrime é um processo eficiente que permite importar rapidamente os dados do Censo Escolar para sua instituição.

## Como importar Dados

Siga estes passos para realizar a Importação dos Dados de Censo:

1. **Acessar o Importador**
   - Na tela inicial, clique em **Censo Escolar** no menu à esquerda

![Importação Inicial](/import1.png)

2. **Selecionar arquivo**
   - Clique em **Selecione o arquivo do Censo Escolar**
   - Localize em seu computador o arquivo com os dados do Censo
> ℹ️ Certifique-se de que o arquivo está no formato correto do Censo Escolar
   - Clique em **Abrir**

![Importação 2](/import2.png)

3. Confira se o arquivo selecionado está correto e clique em **Converter Arquivo**
> ✅ Um alerta confirmará que o Censo foi processado com sucesso
4. Confira as informações no **Resumo do Censo**

![Importação 3](/import3.png)

5. Se todas as informações estiverem corretas, clique em **Importar Dados**
> ℹ️ O processo de importação pode ser acompanhado na tela

![Processo de Importação](/import-processo.png)

6. Quando a importação for concluída, a mensagem **Importação 100% Bem-sucedida!** será exibida.

![Conclusão de Importação](/import-final.png)

> ✅ Os dados de Censo Escolar já estão disponíveis no seu sistema EduPrime.

## Observações Importantes

⚠️ Certifique-se de que o arquivo esteja no formato oficial do Censo Escolar

⚠️ O processo de importação não pode ser interrompido após o início

⚠️ A importação substituirá dados existentes com as mesmas referências

⚠️ Verifique cuidadosamente o resumo antes de confirmar a importação

⚠️ O tempo de importação varia conforme o tamanho do arquivo e quantidade de dados

## Dúvidas Frequentes

1. Quais formatos de arquivo são aceitos pelo importador?

   > O sistema aceita exclusivamente o formato oficial do Censo Escolar. Certifique-se de usar o arquivo gerado pelo sistema do Censo.

2. O que acontece se a importação for interrompida?

   > **A importação será invalidada**. Você precisará reiniciar todo o processo desde o início. Recomendamos não fechar a janela durante o processo.

3. Posso importar dados parciais do Censo?

   > **Não**. O importador processa o arquivo completo do Censo. Para ajustes, após a importação, utilize as funcionalidades do sistema.

4. Como saber se meu arquivo do Censo é compatível?

   > O sistema validará automaticamente o arquivo durante a conversão. Se houver erro na conversão, o arquivo pode estar em formato incorreto ou corrompido.

5. Os dados atuais serão perdidos na importação?

   > **Não**. A importação do Censo substituirá os dados equivalentes, mas irá manter todos os dados cadastrados anteriormente. Seus dados estão seguros.

6. Posso visualizar os dados antes de confirmar a importação?

   > **Sim**. O **Resumo do Censo** mostra todas as informações que serão importadas. Verifique cuidadosamente antes de clicar em **Importar Dados**.

7. Quanto tempo leva o processo de importação?

   > O tempo varia conforme o tamanho da instituição e quantidade de dados. Pode levar de alguns minutos a poucas horas para instituições com muitos cadastros.

8. O que fazer se a importação falhar?

   > Tente executar novamente a importação. Caso o erro persista entre em contato com a Softagon informando o erro exibido e o arquivo utilizado. Nossa equipe analisará o problema.
