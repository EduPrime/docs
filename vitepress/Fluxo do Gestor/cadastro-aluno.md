# Cadastro de Aluno

O **Cadastro de Aluno** no EduPrime permite ao Gestor registrar e gerenciar todos os Alunos da instituição, organizando informações completas desde dados pessoais até histórico educacional.

## Como cadastrar Aluno

Siga estes passos para realizar o **Cadastro de Aluno**

1. **Acessar o Cadastro de Aluno**
   - Na tela inicial, clique em **Alunos** no menu à esquerda

2. Clique no botão **+ Novo Aluno**

3. Preencha a aba **Dados Pessoais**
   - Informe nome completo, data de nascimento, gênero
   - Preencha dados de contato (email, telefone)
   - Adicione endereço completo

> ℹ️ Os dados obrigatórios estão marcados com *

4. Complete a aba **Documentação**
   - Informe CPF, RG, certidão de nascimento
   - Adicione dados de identidade e documentação complementar

5. Preencha a aba **Filiação e Responsáveis**
   - Cadastre os dados dos pais ou responsáveis
   - Defina os contatos de emergência
   - Estabeleça os vínculos familiares

6. Configure a aba **Informações de Saúde**
   - Informe condições médicas relevantes
   - Adicione alergias, medicamentos e restrições

7. **Configurar Matrícula** (opcional)
   - Clique em **+ Ativar Matrícula** para vincular o Aluno a uma Turma
   > 💡 **Dica**: A matrícula pode ser feita posteriormente

8. Confira todas as informações e clique no botão **Salvar**

> ✅ Um alerta confirmará que o Aluno foi cadastrado com sucesso

## Como alterar Aluno

Caso seja necessário realizar alterações nas informações do Aluno, siga estes passos:

1. **Acessar Cadastro de Aluno**
   - Na tela inicial, clique em **Alunos** no menu à esquerda

2. Clique no ícone ✏️ (lápis) presente no lado direito do Aluno que deseja alterar

3. Faça todas as alterações necessárias
   > ℹ️ É possível alterar dados pessoais, documentação e informações de saúde

4. Clique em **Salvar**

> ℹ️ Caso tenha feito alterações indesejadas e não deseja salvá-las, basta clicar no botão **Cancelar** ou **Reverter Alterações**

## Como excluir um Aluno

1. **Acessar Cadastro de Aluno**
   - Na tela inicial, clique em **Alunos** no menu à esquerda

2. **Localizar o Aluno**
   - Encontre o Aluno que deseja excluir na lista
   - Clique no ícone 🗑️ (lixeira) no lado direito

3. **Confirmar Exclusão**
   - **Cenário 1**: Sem vínculos
     - Clique em **Excluir Aluno** para confirmar
   
   - **Cenário 2**: Com vínculos
     - O sistema exibirá um aviso de segurança
     - Exclua ou transfira os cadastros vinculados primeiro
     - Retorne para concluir a exclusão do Aluno

## Observações importantes

⚠️ Campos marcados com * são obrigatórios para concluir o cadastro

⚠️ Certifique-se de **salvar** as alterações antes de sair da tela

⚠️ O campo **Matrícula do Aluno** é **opcional** no momento do cadastro

⚠️ A matrícula pode ser ativada a qualquer momento usando o botão **+ Ativar Matrícula**

⚠️ Os Status disponíveis para Aluno são: **Ativo**, **Inativo**, **Graduado**, **Suspenso** e **Transferido**

⚠️ Alterações no Status do Aluno irão impactar relatórios

⚠️ Mantenha as informações de saúde sempre atualizadas para segurança do Aluno

## Dúvidas Frequentes

1. É obrigatório preencher todas as abas do cadastro?

    > **Não**. Apenas a aba **Dados Pessoais** com campos obrigatórios é necessária para salvar o cadastro inicial.

2. Quando devo usar o botão **+ Ativar Matrícula**?

    > Use este botão quando desejar vincular o Aluno a uma Turma específica. A matrícula pode ser feita a qualquer momento.

3. O que significa cada Status do Aluno?

    > - **Ativo**: Aluno regularmente matriculado e frequentando as aulas
    > - **Inativo**: Aluno cadastrado mas sem matrícula ativa
    > - **Graduado**: Aluno que concluiu o curso com sucesso
    > - **Suspenso**: Aluno temporariamente afastado por decisão disciplinar
    > - **Transferido**: Aluno que foi transferido para outra instituição

4. Posso alterar o Status de um Aluno durante o ano letivo?

    > **Sim**. O Status pode ser alterado conforme a situação do Aluno, mas mudanças podem impactar relatórios e estatísticas.

5. Quantos Responsáveis posso cadastrar para um Aluno?

    > **Múltiplos Responsáveis**. Você pode cadastrar quantos Responsáveis forem necessários para o Aluno.

6. O que acontece se eu tentar excluir um Aluno com matrícula ativa?

    > O sistema exibirá um aviso de segurança. Você precisará cancelar a matrícula primeiro antes de excluir o Aluno.

7. Posso cadastrar o mesmo Aluno com CPF duplicado?

    > **Não**. O sistema não permite CPF e código INEP duplicado para Alunos.

8. O que fazer se não consigo salvar o Cadastro do Aluno?

    > Verifique se:
    > - Todos os campos obrigatórios (*) na aba Dados Pessoais estão preenchidos
    > - O CPF não está duplicado no sistema
    > - Os dados estão em formatos válidos
    > Se o problema persistir, entre em contato com a Softagon.

9. Como faço para matricular um Aluno em uma Turma?

    > Use o botão **+ Ativar Matrícula** no cadastro do Aluno e selecione a Turma desejada.

10. Posso transferir um Aluno de uma Turma para outra?

    > **Sim**. No campo de **Matrícula** faça a alteração para a Turma desejada. Isso impactará na exibição de frequências, avaliações e relatórios.
