# Cadastro de Escola

O **Cadastro de Escola** no EduPrime permite ao Gestor cadastrar e gerenciar todas as escolas da instituição de forma organizada e eficiente.

## Como Cadastrar Escola

Siga estes passos para realizar o **Cadastro de Escola**

1. **Acessar Cadastro de Escola**
- Na tela inicial, clique em **Escolas** no menu à esquerda

2. Clique no botão **+ Nova Escola**

3. Preencha todos os **Dados Gerais** da sua Escola

> ℹ️ Os dados obrigatórios estão marcados com *

4. Clique nas abas da parte superior (**Infraestrutura**, **Dependências**, **Equipamentos**, **Recursos** e **Dados de Ensino**) e preencha as informações necessárias

5. Confira todas as informações e clique no botão **Salvar**

> ✅ Um alerta confirmará que a Escola foi cadastrada com sucesso


## Como alterar Escola

Caso seja necessário realizar qualquer alterações de informações da sua Escola, basta seguir os seguintes passos:

1. **Acessar o Cadastro de Escola**
- Na tela inicial, clique em **Escolas** no menu à esquerda

2. Clique no ícone ✏️ (lápis) presente no lado direito da Escola que deseja realizar alterações

3. Faça todas as alterações necessárias

4. Clique em **Salvar**

> ℹ️ Caso tenha feito alterações indesejadas e não deseja salvá-las, basta clicar no botão **Cancelar** ou **Reverter Alterações**


## Como excluir Escola

Caso queira excluir Escola do nosso sistema, basta seguir os seguintes passos:

1. **Acessar Cadastro de Escola**
- Na tela inicial, clique em **Escolas** no menu à esquerda

2. **Localizar a Escola**
   - Encontre a Escola que deseja excluir na lista
   - Clique no ícone 🗑️ (lixeira) no lado direito

3. **Confirmar Exclusão**
   - **Cenário 1**: Sem vínculos
     - Clique em **Excluir Escola** para confirmar
   
   - **Cenário 2**: Com vínculos
     - O sistema exibirá um aviso de segurança
     - Exclua ou transfira os cadastros vinculados primeiro
     - Retorne para concluir a exclusão da Escola


## Observações importantes

⚠️ Campos marcados com * são obrigatórios para concluir o cadastro

⚠️ Certifique-se de **salvar** as alterações antes de sair da tela

⚠️ Recomendamos checar todas as abas para garantir um cadastro completo da escola

⚠️ A exclusão de escola só é possível quando não há outros cadastros vinculados

⚠️ Dados da escola podem ser alterados a qualquer momento


## Dúvidas Frequentes

1. Quais são os dados obrigatórios para cadastrar uma escola?

    > Apenas os campos marcados com * são obrigatórios.

2. Posso cadastrar quantas escolas desejar?

    > **Sim**. Não há limite de escolas por instituição no EduPrime.

3. O que acontece se eu tentar excluir uma escola com cadastros vinculados?

    > O sistema exibirá um aviso de segurança listando os cadastros vinculados. Você precisará excluir esses cadastros primeiro.

4. O sistema não deixa eu excluir uma Escola. O que eu faço?

    > Para garantir a segurança e evitar exclusões acidentais, o sistema EduPrime não permite que uma Escola seja excluída caso tenham outros cadastros vinculados à ela. O sistema irá mostrar quais os cadastros vinculados para facilitar a exclusão deles individualmente.

5. Posso duplicar o cadastro de uma escola para criar uma similar?

    > **Não**. Atualmente não há função de duplicação. Cada escola deve ser cadastrada individualmente.

6. Posso transferir cadastros entre escolas?

    > **Sim**, mas deve ser feito manualmente. Para transferir cadastros de uma escola para outra:
    > - Acesse individualmente cada cadastro vinculado (alunos, professores, etc.)
    > - Altere a escola de vínculo no respectivo cadastro
    > - Isso garante a segurança dos dados e evita duplicações

7. Posso reativar uma escola excluída acidentalmente?

    > **Não**. A exclusão é definitiva. Entre em contato com a Softagon para verificar possibilidade de recuperação via backup.

8. O que fazer se não consigo salvar o cadastro da escola?

> Verifique se:
> - Todos os campos obrigatórios (*) estão preenchidos
> - Não há caracteres inválidos nos campos
> - Todas as abas foram devidamente preenchidas
> Se o problema persistir, entre em contato com a Softagon.

9. Posso cadastrar uma escola de forma parcial e completar depois?

    > **Sim**. Você pode salvar o cadastro básico e retornar depois para completar as abas restantes.
